# One Space Issue Tracker Terminology

* **Member:** A user assigned the standard role capable of creating, assigning, editing, and moving work items.
* **Admin:** A user assigned the administrative role, with permissions to manage members, registration invitations, projects creation/settings.
* **Project:** A collection of related issues/tasks.
* **Issue/Task:** The fundamental unit of work.
* **Project Key:** A unique, short alphanumeric code assigned to project (e.g., `WEB`, `MOB`).
* **Issue Key:** A unique, short alphanumeric code combined from project key and issue number (id) (e.g., `WEB-1`, `MOB-101`).
* **Backlog:** Queued issues planned for future work but not currently active.
* **Todo / Unstarted:** Prioritized issues ready to be picked up by a team member.
* **In Progress / Active:** Work actively being developed.
* **Completed / Done:** Successfully finished work.
* **Assignee:** The single team member responsible for delivering the issue.
* **Priority:** Core importance tiers (`Urgent`, `High`, `Medium`, `Low`, `No Priority`).
